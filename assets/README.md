# Grapleton artwork

The grape-and-cubby mark and bottle illustrations are original artwork created for the Grapleton prototype. They contain no third-party logos, photographs or fonts.

- `grapleton-mark.svg` is the product mark. Use its full square view box. Give it empty alternative text when the Grapleton name already appears beside it.
- `icon-192.png` and `icon-512.png` are solid-background exports for install surfaces. The grape and cubby are inside the maskable safe area.
- `bottle-*.svg` are decorative wine-style illustrations for records without a photo. Render with empty alternative text and include the actual wine style in adjacent text when it matters.
- `cellar-serif.woff2` is Instrument Serif Regular, distributed under the SIL Open Font License in `instrument-serif-OFL.txt`.
